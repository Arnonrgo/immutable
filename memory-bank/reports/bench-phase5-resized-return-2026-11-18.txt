Phase 5 follow-up: mapNode set/delete return (node, added|removed) instead of *bool
===================================================================================
toolchain: go1.27.4 darwin/arm64 (Apple M1 Pro), heavily loaded machine.
Old = a5ab24e, new = working tree. 5 interleaved rounds of 100 ms, minimum ns/op.
B/op and allocs/op are exact. Time ratios of 0.97-1.10x are noise at this load.

Why: Map.Set passed &resized to an interface method, so it was heap-allocated.
Evidence: Set overwriting a key on a 20-entry map took 5 allocations; Map clone (1)
plus node.set (3) is 4. (-gcflags=-m does not report the generic instantiation.)
